# 使い方

Window Rescue は、見えない位置や操作できないサイズで開いたウインドウを、今使っている画面へ移す Windows 11 用の常駐アプリです。

## 起動

- `WindowRescue.exe` を実行すると通知領域（トレイ）に常駐し、ミニウインドウを表示します。既存の窓は動かしません。
- もう一度起動しても常駐プロセスは増えず、既存のアプリにミニウインドウを表示させます。
- 設定ファイル：`%LOCALAPPDATA%\WindowRescue\settings.json`（この PC 内だけに保存）

## ミニウインドウ

画面に小さく常駐する操作ウインドウです。置かれている画面を「この画面」として扱います。

| 項目 | 動作 |
| --- | --- |
| 新しい窓をこの画面に出す | 新しく開いた窓をこの画面へ移します。ミニウインドウを別の画面へ動かすと、表示先も追従します。 |
| 小さい窓を補正する | チェックを入れた時点で、今開いている極小の窓を補正します。以後に開く極小の窓も自動で拡大します。 |
| 窓をこの画面に集める | 全ウインドウをこの画面へ移します。 |

- × で閉じると隠れるだけで、アプリは終了しません。
- トレイアイコンの左クリックで前回の位置に、トレイの右クリックメニュー「ミニウインドウを表示」でカーソル位置に表示します。

## デスクトップの右クリックメニュー

設定の「右クリックメニュー」で登録すると、デスクトップの何もない場所を右クリックしたメニュー（Windows 11 では「その他のオプションを確認」）に「ウインドウ救出」が追加されます。

- この画面へ全ウインドウを救出
- ミニウインドウを表示（カーソル位置に表示）
- ウインドウ一覧
- 設定

タスクバー（トレイ）が見えない画面でも、見えている画面のデスクトップから操作できます。たとえば、入力を別の PC へ切り替えた画面にタスクバーがある場合でも、手元の画面で右クリックしてその画面へ窓を集められます。アプリが起動していないときは、起動してから操作を実行します。

## トレイメニュー（右クリック）

- この画面へ全ウインドウを救出
- 新しい窓をこの画面（画面 n）に表示（チェック項目）
- ミニウインドウを表示／救出パネル／ウインドウ一覧／設定
- 管理者として再起動（管理者権限で動くアプリの窓を移すとき）
- 終了

メニューを開いたときにカーソルがあった画面を「この画面」として扱います。

## ウインドウ一覧

見えていない窓も文字で探せます。アプリ名・プロセス名・タイトル・所在画面・座標・大きさ・状態と、「極小」「一部が画面外」「操作不可」などの問題を表示します。検索、問題のある窓だけの絞り込み、複数選択ができ、選んだ窓を救出先へ移します（最小化中の窓は表示し直します）。

## 設定

- **新しい窓の自動救出**：監視しない／自動救出（画面外・はみ出し・極小の窓だけ補正）／表示先を固定
- **自動サイズ補正**、極小と判定する幅・高さ、標準救出サイズ（DIP）
- **除外するアプリ**：自動補正の対象外にするアプリ（すべて／サイズ補正だけ）
- **ショートカット**：割り当ての変更・解除。他のアプリと重なって使えないキーは表示で分かります
- **右クリックメニュー**：デスクトップの右クリックメニュー（Windows 11 では「その他のオプションを確認」）への登録・解除。アプリを移動した後や更新後は「登録を修正する」で作り直します
- **言語 / Language**：Windows に合わせる／日本語／English（再起動不要）
- **起動と権限**：サインイン時の自動起動、管理者として再起動

## ショートカットの初期値

| 操作 | キー |
| --- | --- |
| 選択中の窓を画面 1／2／3 へ | Ctrl + Alt + 1／2／3 |
| 全ウインドウを画面 1／2／3 へ | Ctrl + Alt + Shift + 1／2／3 |
| ウインドウ一覧を開く | Ctrl + Alt + Space |
| ポインターのある画面へ全ウインドウを救出 | Ctrl + Alt + Home |

画面番号は救出パネルやウインドウ一覧の選択欄（「画面 1：機種名…」）で確認できます。接続の順番が変わっても同じ画面に同じ番号を使います。

## 起動引数

`--action rescue-here | list | settings | panel | mini`、`--background`（ミニウインドウを前回非表示にした場合は常駐のみ）

## 制約

- 管理者権限で動くアプリの窓は、本アプリを管理者として再起動しないと移動できない場合があります。
- 別の仮想デスクトップの窓、独占フルスクリーンのゲーム、UAC などの保護された画面は対象外です。
- 窓の外枠を動かすだけで、アプリ内部のレイアウトまでは保証しません。
